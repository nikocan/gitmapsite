# Gitmapp Türkiye meslek ve beceri kataloğu

meslekler.csv içindeki 1.000 meslek kodu 439 farklı dört haneli meslek birim kodunu kapsar. Kod ve unvan kaynağı Eğirdir Mesleki Eğitim Merkezi tarafından yayımlanan SGK / İşKur Meslek Kod Listesi, belge sürümü 54. Bu seçim tüm unvanların dökümü değildir. Birim kodlarından çeşitlendirilmiş örnekleme yapılmıştır. Uygulama önerileri ve paket atamaları Gitmapp için hazırlanmış başlangıç hipotezleridir. Kurumun kullandığı gerçek süreçleri ve entegrasyonları proje keşfinde doğrulayın.

## Kullanım
Bu klasörde Python 3 ile:
- python gt.py kuyumcu
- python gt.py 1420.06
- python gt.py 2211.02
- python demo_social.py

CSV'de kod, unvan, paket, uygulama, iş akışı ve kabul testi yer alır. 29 ortak meslek ailesi, beş bağımsız sosyal yayın ve iki sistem yazılımı becerisi packs altında bulunur. Sistem programcısı için os-emulator, kumanda uygulaması için remote-control paketini hedefe göre seçin. Sosyal paketleri meslek paketine ekleyin. Örneğin kuyumcu stok yönetimine instagram eklenebilir. Dış yayın öncesinde içerik sürümüne açık onay alın. Canlı sağlayıcı adaptörleri, erişim belirteçleri ve klinik karar desteği bu katalogda sunulmaz.
