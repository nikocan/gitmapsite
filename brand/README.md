# Gitmapp squirrel

A squirrel turns an acorn in its paws before deciding where to plant it. In Gitmapp, that acorn is a brief. A maker can start from a template, open the studio, select an element and shape it into an app of their own.

The squirrel looks straight ahead. Its tail is a single-storey lowercase g. The oval counter, thick stem and open descender echo the Inter wordmark. Use the whole animal at small sizes. The tail gives a single flick when the desktop brand appears. On hover, the nose dips twice towards the acorn. Both gestures respect the device’s reduced-motion setting.

Pair the mark with the existing lowercase **gitmapp.** wordmark in Inter ExtraBold, with tight tracking and the citrus period. Use Citrus (#E4FF3D) and Ink (#101211) for the signature. Paper (#F2F0E6) and Fern (#204E40) are supporting campaign colors.

## Assets

- `squirrel.svg` contains the single-color master with separate tail, body, head and acorn groups.
- `app-icon.svg` and the three PNGs in `pwa/` form the favicon and install icon family. Run `python tools/build_brand.py` with Inkscape installed to regenerate them.
- `ecosystem.svg` contains 12 symbols designed on a 24-unit grid with rounded joins and a 1.65-unit stroke. The acorn starts an idea, layered sheets introduce templates, a nib opens the studio and a paper plane means publish. Use the same symbols across mobile navigation and the desktop sidebar.
- `motion.css` defines the squirrel’s gestures.

The mark was studied at small sizes alongside GitHub’s official 16- and 24-pixel Octicons. GitHub account and repository actions retain the GitHub identity. [GitHub’s Octicon](https://primer.style/octicons/mark-github-16)

The yellow bee is a companion in the campaign artwork. Each translucent wing carries the same readable lowercase g. Its standalone mark is in `bee.svg`.
