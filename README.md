# Gitmapsite

GitHub'daki açık kaynak projeleri keşfeden, iş kollarına göre kategorize eden, güvenlik testinden geçiren, arayüz ekranlarından sunum hazırlayan ve seçilen projeyi geliştirip canlıya alma akışını yöneten web uygulaması.

- Canlı: https://nikocan.github.io/gitmapsite/
- Sürüm notları: uygulama içinde **Güncellemeler** sekmesi
